Confronto tra Javascript e jQuery

Lo stesso codice scritto in due modi

Javascript "puro"

                    'use strict'
                    let btn=document.getElementById('btn')
                    btn.click=()=>{
                        let p = document.querySelectorAll('p')
                        for(let i=0;i < p.length;i++){
                            p[i].style.color='red'
                        }
                    }

jQuery

                        $('#btn').on('click',()=>{
                            $('p').css('color','red')
                        })
